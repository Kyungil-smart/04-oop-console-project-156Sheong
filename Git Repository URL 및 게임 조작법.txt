## A. 게임 소개
- 자신의 우주 함대로 필드 맵을 돌아다니면서 우주 해적을 잡는 게임
- 필드 맵에는 **수리(⚓)**, **연료(🛢️)**, **재화(💰)**, **랜덤(❓)** 등 각종 오브젝트 배치됨
- 우주 해적은 **경고 표시(🚨)** 로 나타나며, 해당 그리드와 충돌 시 전투 돌입
- 전투는 전투 맵에서 이뤄지며, 여러 척의 아군 함선과 적군 함선이 속도가 빠른 순서대로 번갈아가며 거리 상 가까운 적을 공격
- 전투 승리 시, 아군 함대의 레벨이 오르고, 이에 따라 모든 아군 함선의 능력치 상승
- 특정 횟수 이상 전투 승리 시, 새로운 적이 등장

  

## B. 승리 패배 조건
- **승리**
  - 17회 이상 전투 승리 시, 게임이 클리어 되며 데모 버젼이 종료
- **패배**
  - 필드 맵에서 연료가 0 이하가 되면 게임 오버
  - 적에게 아군 함선이 모두 제거되면 게임 오버



## C. 기타 사항
- 계속 업데이트 할 예정

# 추후 개선 사항 목록

## 데이터 관리 관련
1. Json 파일 파서 만들고, 각종 데이터는 Json 으로 관리



## 인풋 관련
1. 키 입력 받으면 종류 별로 묶기 (방향키 4종, 확인, 취소)



## 사운드 관련
1. 배경음 말고 효과음도 넣기
2. 사운드도 씬처럼 이름으로 불러오도록, int 배열 말고 딕셔너리나 다른 자료형으로 넣기
3. 사운드 종류별로 묶어서 조건에 맞으면 해당 사운드 종류에서 랜덤으로 재생하도록 만들기



## 번역 관련
1. 언어 설정을 옵션에 넣고 로컬라이제이션 파일을 따로 만들기



## 전투 관련
1. CombatManager에서 아군이 아니어도, 중립이면 공격 안하도록 수정하기

## 인트로 문구
- 자유는 어디서 오는가?

- 체제인가? 공간인가?
- 개인의 신분이나 물질적 풍요인가?
- 아니면 내면의 상태인가?



## 인트로 문구 (구버젼)
- 첫번째 배신자는 반역자
- 두번째 배신자는 무법자
- 세번째 배신자는 찬탈자

- 그렇다면 네번째 배신자는?



## 게임의 주제
- 자유란 무엇인가
- 각각 자유의 속성에 대한 반례 사례를 많이 들기 -> 반례를 통한 자유에 대한 고민을 위함(소크라테스의 문답법에 영감 받음)
  - 자유로운 우주에서 자유롭지 않은 경우
  - 자유롭지 않은 제국에서 자유로운 경우
  - 자유로은 체제에서 자유롭지 않은 경우
  - 자유 신분이지만 무언가에 속박되는 경우
  - 금전적으로 자유롭지만 금전에 계속 속박되는 경우
  - 본인은 자유롭다 생각하지만 외부에서 볼 때는 그렇지 않은 경우 ([그들은 자신들이 자유롭다고 생각했다] 처럼)
  - 자신은 자유롭지만 그 자유가 남의 자유를 침해하는 경우
    - 우주 해적의 약탈
    - 거대 기업의 행성 지배와 착취 ([영국 동인도회사령 인도] 처럼)
