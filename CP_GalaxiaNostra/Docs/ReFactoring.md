# 추후 개선 사항 목록

## 데이터 관리 관련
1. Json 파일 파서 만들고, 각종 데이터는 Json 으로 관리


## 인풋 관련
1. 키 입력 받으면 종류 별로 묶기 (방향키 4종, 확인, 취소)


## 사운드 관련
1. 배경음 말고 효과음도 넣기
2. 사운드도 씬처럼 이름으로 불러오도록, int 배열 말고 딕셔너리나 다른 자료형으로 넣기
3. 사운드 종류별로 묶어서 조건에 맞으면 해당 사운드 종류에서 랜덤으로 재생하도록 만들기


## 번역 관련
1. 언어 설정을 옵션에 넣고 로컬라이제이션 파일을 따로 만들기


## 전투 관련
1. CombatManager에서 아군이 아니어도, 중립이면 공격 안하도록 수정하기
2. 자동 전투 중 아군과 적 생명력 실시간 생명력을 UI가 변경하는 기능 필요
3. 현재 적군 함대 레벨 10으로 표시되는 버그 있음

## 인트로 문구
- 자유는 어디서 오는가?

- 체제인가? 공간인가?
- 개인의 신분이나 물질적 풍요인가?
- 아니면 내면의 상태인가?


## 인트로 문구 (구버젼)
- 첫번째 배신자는 반역자
- 두번째 배신자는 무법자
- 세번째 배신자는 찬탈자

- 그렇다면 네번째 배신자는?


## 게임의 주제
- 자유란 무엇인가
- 각각 자유의 속성에 대한 반례 사례를 많이 들기 -> 반례를 통한 자유에 대한 고민을 위함(소크라테스의 문답법에 영감 받음)
  - 자유로운 우주에서 자유롭지 않은 경우
  - 자유롭지 않은 제국에서 자유로운 경우
  - 자유로은 체제에서 자유롭지 않은 경우
  - 자유 신분이지만 무언가에 속박되는 경우
  - 금전적으로 자유롭지만 금전에 계속 속박되는 경우
  - 본인은 자유롭다 생각하지만 외부에서 볼 때는 그렇지 않은 경우 ([그들은 자신들이 자유롭다고 생각했다] 처럼)
  - 자신은 자유롭지만 그 자유가 남의 자유를 침해하는 경우
    - 우주 해적의 약탈
    - 거대 기업의 행성 지배와 착취 ([영국 동인도회사령 인도] 처럼)
